The User Role Aggregator App is designed to streamline the management of User administrator user roles in DHIS2, meaning creating and managing user roles of users who should manage other users. It provides an easy-to-use interface to create new user roles that manage specific roles and modify existing user roles to add or update their managed roles. The app is based on the DHIS2 users management concept that requires a user to have the same or more privileges than the users they manage.
